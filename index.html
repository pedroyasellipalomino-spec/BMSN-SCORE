Cómo funciona

Todo vive en GitHub. Los datos están en la carpeta data/ del repositorio. Cuando anotas un plan, añades una persona, creas una encuesta o votas, esta página abre un issue de GitHub ya rellenado. Solo tienes que pulsar Submit new issue.

Una GitHub Action lee el issue, comprueba quién lo envía, guarda el cambio en data/, responde en el issue y lo cierra. En uno o dos minutos la página se actualiza.

Votos verificados

  • Cada voto sale de una cuenta de GitHub. GitHub solo deja abrir issues a cuentas con el correo electrónico verificado.
  • Además, solo cuentan los votos de usuarios de GitHub registrados en Personas.
  • Un voto por cuenta y por encuesta. Si vuelves a votar, se reemplaza tu voto anterior.
  • Solo se aceptan votos durante el mes de la encuesta.

Permisos

Anotar planes, personas y encuestas está reservado a los admins definidos en data/config.json (y al dueño del repositorio).
